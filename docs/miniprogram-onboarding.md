## 二、必须完成的外部配置（按顺序）

### 1️⃣ 云开发控制台：绑定小程序（授权方式=接管模式）
1. 登录 [腾讯云 CloudBase 控制台](https://console.cloud.tencent.com/tcb) → 环境 `zhenhesheng-d6gkez7p221305432`
2. 左侧 **环境 → 用户管理 / 登录授权** → **微信小程序授权**
3. 点击「添加小程序」→ 输入 AppID：`wx3ec1337aae9ace3c`
4. 授权方式选择 **「接管模式」**（云开发接管小程序用户体系，登录态由云开发管理）
5. 确认绑定成功后，云函数内 `getWXContext().OPENID` 即可直接取到用户身份（已实现，无需 secret）

### 2️⃣ 微信公众平台：获取 AppSecret（可选，接管模式可跳过）
- 如不启用接管模式，需在 [微信公众平台](https://mp.weixin.qq.com) 开发管理 → 开发设置 获取 AppSecret
- 将 `WX_APPID` / `WX_SECRET` 配置到云函数 `dy-api` 的**环境变量**（云开发控制台 → 云函数 → dy-api → 配置）
- 接管模式下不需要，代码已自动优先走 `getWXContext()`

### 3️⃣ 云开发控制台：开通微信支付（需要商户号）
1. 云开发控制台 → **微信支付** → 点击「开通」
2. 关联你的 **微信支付商户号（mchid）**：
   - 若商户号已关联该小程序 AppID，选择普通商户模式
   - 若是服务商模式，选择服务商模式并填 `sub_mchid`
3. 开通后：
   - 普通商户模式：无需在代码填商户号
   - 服务商模式：把 `sub_mchid` 填入 `cloudfunctions/dy-api/config.local.js` 的 `WXPAY_MCHID`（该文件已 gitignore，不会入库），然后重新部署云函数
4. 支付成功后系统自动回调 `dy-api`，订单状态更新为「待发货」并推送站内信

### 4️⃣ 微信开发者工具：导入开发版
1. 打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（需管理员/开发者扫码登录）
2. 导入项目：
   - 目录：`dist/build/mp-weixin`
   - AppID：`wx3ec1337aae9ace3c`
   - 后端服务：**微信云开发**（如弹窗选择，选「不使用云服务」改为在 app.js 自动 init，本项目已内置 wx.cloud.init）
3. 本地编译 → 真机预览（扫码体验开发版）

### 5️⃣ 合法域名（小程序端基本免配置）
- `wx.cloud.callFunction / uploadFile` 走云开发通道，**无需配置合法域名**
- 云存储图片展示（`https://7a68-...tcb.qcloud.la/...`）：云开发环境自动加入白名单，一般无需手动配置；如个别机型加载失败，在公众平台 → 开发管理 → 开发设置 → 服务器域名 → downloadFile 合法域名添加 `https://7a68-zhenhesheng-d6gkez7p221305432-1309518368.tcb.qcloud.la`

## 四、注意事项

1. **虚拟支付限制**：AI 解盘 ¥9.9 解锁、AI 问答 ¥1 属于虚拟内容，微信小程序对虚拟支付有资质要求（iOS 端虚拟支付受限）。当前 AI 解锁为演示流程（本地解锁），正式上架前建议：
   - 购买实物（商品订单）走微信支付（已实现 ✅）
   - AI 增值服务可改为「余额支付」（用户先充值余额再消费），或接入微信虚拟支付（需类目资质）
2. **云函数部署**：修改 `cloudfunctions/dy-api` 后需重新部署（`tcb fn deploy dy-api`），本轮已部署
3. **商户号敏感信息**：`config.local.js` 已 gitignore，`WXPAY_MCHID` 不进仓库
4. **版本号**：小程序版本号建议与 APP 版本保持一致（当前 2.0.0），每次发版同步更新

## 六、小程序扫码接管（v2.0.1 新增，仿扣子平台）

后台「小程序接管」模块已实现**第三方平台扫码授权**：填 AppID → 生成授权链接 → 管理员扫码 → 自动接管，后续可在线上传开发版 / 取体验码 / 提审 / 发布。

### 开放平台侧配置（一次性，需企业认证的微信开放平台账号）
1. 登录 [微信开放平台](https://open.weixin.qq.com) → 「管理中心 → 第三方平台 → 创建第三方平台」（需企业主体，按提示填资料）
2. 创建后拿到：**AppID（component_appid）** 与 **AppSecret（component_secret）**
3. 在第三方平台「开发配置」中设置：
   - **授权事件接收 URL**：`https://cloud1-d8gs2k9m311f7272f-1464523137.ap-shanghai.app.tcloudbase.com/dy-api?action=wxmp.authCallback`
   - **消息校验 Token**：自定义一串随机字符（如 `daoyuan2026`）
   - **消息加密 Key（EncodingAESKey）**：点击随机生成
   - 该 URL 需通过微信的 GET 验证（云函数已实现 echostr 解密回显）
4. 把以上 4 项填入 `cloudfunctions/dy-api/config.local.js`（WXMP_COMPONENT_APPID / WXMP_COMPONENT_SECRET / WXMP_TOKEN / WXMP_AES_KEY），重新部署云函数

### 使用流程（后台操作）
1. 后台 → 「小程序接管」→ 「＋绑定小程序」→ 填目标小程序 AppID → 生成授权链接
2. 复制链接 → 用该小程序**管理员微信**打开 → 扫码确认授权
3. 授权成功 → 列表出现该小程序（已接管）→ 可操作：**体验码 / 上传开发版 / 提审 / 发布**

### 说明
- 上传开发版使用微信「模板」机制：首次需在**微信开发者工具**导入项目上传一次（生成草稿），云函数会自动把草稿转为模板；之后上传全自动
- 取消授权（小程序管理员在公众平台解除）后，列表状态自动变「已取消」

## 七、服务号消息推送（小程序消息 → 同主体服务号）

代码已实现完整链路（绑定页 + 订阅授权 + 自动推送），需在服务号后台完成 3 项配置：

### 服务号侧配置（一次性）
1. **确认服务号已微信认证**（订阅通知 + 网页授权均要求认证服务号）
2. 服务号后台 → 设置与开发 → 基本配置 → **网页授权域名**：添加
   `cloud1-d8gs2k9m311f7272f-1464523137.tcloudbaseapp.com`
   （绑定 openid 的授权回调域名）
3. 服务号后台 → 功能 → **订阅通知** → 申请一个模板：
   - 搜索"通知"类模板，选择带 **thing1 + thing2** 字段的（如"订单通知"）
   - 若申请到的模板字段不同（如 thing1+time1），告知开发改 `GZH_TEMPLATE_FIELDS` 即可

### 云函数配置（config.local.js，已 gitignore）
```
GZH_APPID: '服务号 AppID',
GZH_SECRET: '服务号 AppSecret',
GZH_TEMPLATE_ORDER: '订阅通知模板ID',
GZH_TEMPLATE_FIELDS: 'thing1,thing2',   // 与模板字段一致
```
填完重新部署云函数。

### 推送场景（已接入）
| 场景 | 触发 | 方式 |
|---|---|---|
| 订单支付成功 | 微信支付/余额支付回调 | 单用户 |
| 订单发货 | 后台发货 | 单用户（已有） |
| 新课上线 | 后台新增课程 | 群发（已绑定用户） |
| 盘道活动 | 后台新增场次 | 群发（已绑定用户） |

### 用户侧流程
首页 →「关注服务号 + 开启通知」→ 微信内打开 `gzh-bind.html` → 一键绑定（无感）→ 点「开启微信通知提醒」跳订阅授权页点允许 → 之后每授权 1 次可接收 1 条消息。

> ⚠️ 微信规则：服务号「订阅通知」为一次性授权（1 次授权 = 1 条消息）。如需要无感多次推送，需服务号具备「模板消息」权限（2020 年前注册的老服务号），另行改造。
