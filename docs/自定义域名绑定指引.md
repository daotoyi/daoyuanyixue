## 二、当前要做的（第 1 步）：申请 SSL 证书

**入口**: https://console.cloud.tencent.com/ssl

1. 点「申请免费证书」→ 选 **TrustAsia DV 单域名证书**（免费，1 年）
2. 域名填写: **zhenhesheng.cn**（已备案，无需额外资料）
3. 提交后通常 **几分钟内自动签发**
4. 签发成功后在证书列表复制 **证书 ID**（形如 `abc123` 的短 ID），发给我

> 说明：DV 单域名证书一个域名一张。先申请主域名 zhenhesheng.cn，如果 H5 用的 club 子域名也需要独立证书时再补申请一张 club.zhenhesheng.cn。免费证书额度足够。

---

## 三、第 2 步：CloudBase 绑定（我来执行）

拿到证书 ID 后，我通过 CloudBase MCP 执行：

```
manageGateway bindCustomDomain
  domain = club.zhenhesheng.cn
  certificateId = <你提供的证书ID>
```

绑定成功后平台返回 **CNAME 目标值**，我会转告你。

---

## 四、第 3 步：DNSPod 添加解析（你做）

**入口**: https://console.cloud.tencent.com/cns → 选择 zhenhesheng.cn → 解析设置

添加记录（或修改现有那条 `club` 的 CNAME）：

| 主机记录 | 记录类型 | 记录值 |
|---------|---------|--------|
| club | CNAME | <绑定后返回的 CNAME 目标值> |

⚠️ 注意：当前 `club.zhenhesheng.cn` 已有一条 CNAME 指回 `zhenhesheng.cn`，需要**先删除**再添加新记录，CNAME 不能与同主机名其他类型共存。

DNS 生效一般 **5-30 分钟**。

---

## 五、第 4 步：创建路由（我来执行）

```
manageGateway createRoute
  domain = club.zhenhesheng.cn
  path = /
  upstreamResourceType = STATIC_STORE
  targetName = staticstore
```

## 六、第 5 步：验证

- 浏览器打开 `https://club.zhenhesheng.cn` → 应显示道元易学 H5 首页
- 可用 `nslookup club.zhenhesheng.cn` 确认解析已指向 CloudBase CNAME

## 七、可选：小程序 web-view 打开 H5 需要业务域名

如果小程序内用 `<web-view src="https://club.zhenhesheng.cn">` 打开 H5：

1. 微信公众平台 → 开发 → 开发设置 → **业务域名** → 添加 `club.zhenhesheng.cn`
2. 下载微信提供的 **校验文件**（如 `xxx.txt`），上传到静态托管根目录
3. 审核通过后 web-view 才能打开（个人主体小程序不支持 web-view）
