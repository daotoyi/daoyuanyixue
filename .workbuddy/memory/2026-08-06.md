## 数据嵌套 BUG 修复 (20:17)
- **症状**: 首页/商城/直播空白, 接口返回 {"_id", "data": {...}} 嵌套结构
- **根因**: node-sdk 的 add 是 add(doc) 直接传文档 (dy-api 一直这么用), 我误用 web SDK 的 add({data: doc}) 语法 → 每个文档被包一层 data 字段
- **修复**: 临时云函数 db-import-fix: 清空集合 + add(doc) 逐条重插 (超时默认3s不够→config update fn --timeout 120)
- **验证**: moments/products/live/user.login 全部平铺返回正常 ✅
- **教训**: CloudBase node-sdk (云函数) add 语法 = add(doc); 微信云开发批量 add({data: 数组}) 与 node-sdk 行为不同, 统一逐条 add(doc)
