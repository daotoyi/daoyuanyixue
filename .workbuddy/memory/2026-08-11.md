# 2026-08-11 工作日志

## 排盘记录时间格式统一 v1.11.60 (08:20-08:25)
- 背景: 用户反馈 YYYY-MM-DD HH:mm 时间格式 H5/小程序"都没改好"
- 排查: 线上 chunk 已含 getFullYear(新格式已上线), 保存端三处(tools saveHistory/fmtTime + paipan saveDisk)v1.11.59 已加年份
- **根因**: 用户看到的是**旧记录**(v1.11.59 之前保存的 MM-DD HH:mm), 新格式只对新记录生效
- 解决: 显示端兼容 - paipan-records.vue 和 paipan.vue 历史弹窗新增 **fmtRecTime(rec)**: 已含年份直接返回, 旧格式 MM-DD HH:mm 用 rec.ts 时间戳补年份 → 新旧记录显示统一
- 测试: 新/旧/跨年记录(2025-12-31)格式正确; MP 产物 fmtRecTime 完整打包(paipan-records.js @1059 + paipan.js); H5 部署 109文件; GitHub 已推送
- ⚠️ 经验: 用户报"没改好"时先查是否是旧数据缓存/旧记录, 显示端做兼容格式化比改保存端更彻底
- 版本: 1.11.59 → 1.11.60
