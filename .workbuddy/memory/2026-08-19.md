## v1.11.169 东八区时间+订单表排序+订单分析对齐

- 云函数新增 msToCn/utcStrToCn helper: ms时间戳或UTC字符串 → 北京字符串 "2026/8/19 11:12:46"
- 用户管理: last_active_at(最后在线) msToCn 转东八区; last_login_at(最近登录) utcStrToCn 同步修正
- 订单管理: created_at utcStrToCn 转东八区(下单时间列); adminList 无筛选时也 orderBy created_at desc
- 订单表格: 新增下单时间列(w-time), 金额/下单时间表头可点击排序(orderSort ref + sortedOrders computed + fmtOrderTime 显示 M/D HH:mm), 默认 created_at desc 最新在上
- 订单分析: 去掉 status 过滤(与订单管理·全部口径一致, 12→37); typeMap 补 appointment(预约)+recharge(充值); 历史无 order_type 订单按 order_no 前缀 TL/RC/AP 归类; 前端 pieColors 加第5色, 标题 成交分布→订单分布
- 前端 orderTypeStats 用 classifyOrder 归类(兼容历史订单)+ 增加充值项
- 移动端 orders-table min-width 1560rpx 强制横滑(表头随内容同滚), 宽屏 min-width 0
