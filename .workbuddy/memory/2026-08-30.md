## v1.11.254: 修复后台删除用户不生效 (软删除机制, 重要)
- **根因**: 后台删除用户是物理 remove users 文档, 但三个登录入口(账号密码 login / 微信 wechatLogin / 手机号 phoneLogin)在查不到用户时会**自动注册新账号** → 被删用户一登录账号就复活, 看似"删除不生效"
- **修复**: ①adminUserDelete 改为软删除 — users 文档 update {status:'deleted', deleted_at, deleted_by, session_token:''}(会话立即失效), 关联数据(orders/favorites/footprints/coupons/messages/user_courses/live_bookings/moments)照删; ②三个登录入口查用户后若 status==='deleted' → fail('该账号已被注销，无法登录')(软删除记录保留故不会走自动注册分支); ③userHeartbeat 对 deleted 用户返回 kicked+gone 立即踢下线; ④adminList users 过滤 status==='deleted'; ⑤register 查重天然拦截(记录保留)
- **教训**: 凡"删除用户/封号"类功能必须同时封禁所有登录/注册入口, 否则物理删除会被自动注册绕过
