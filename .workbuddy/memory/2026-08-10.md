## H5 logo/头像不显示真根因+修复 v1.11.49 (10:36-10:50)
- **用户反馈**: 首页 logo、关于我们 logo 在 H5 仍是"只有个框"(米金底容器在但图空白); 我的页面左上角头像不显示但个人主页显示
- **排查方法**: 系统 Chrome headless `--dump-dom` 看渲染后 DOM → uni-app H5 image 组件内部是 `<div style="background-image:...">`+`<img>`
- **真根因①logo**: Vite `publicPath:"./"` 把源码 `/static/logo.png` 编译成相对 `./static/logo.png`; **uni-app H5 image 组件不支持相对路径 src → background-image:none 空白**; 而动态绑定的图片(如 moment-img 接口返回 /static/xxx 绝对路径)不受影响 → 只有静态 logo 挂
- **修复①**: logoUrl 计算属性, H5 用 `window.location.origin + '/static/logo.png'`, 小程序用 `/static/logo.png`; index.vue/about.vue 两处 `:src="logoUrl"`
- **修复②头像**: user.vue onShow 先 userProfile 从后端刷新最新头像(setUserInfo), 再 resolveCloudUrl 转换; 模板 v-if 改仅依赖 displayAvatar(转换成功才显示, 否则 fallback 首字) — 原 v-if 含 userInfo.avatar(可能是 cloud:// 导致 H5 渲染失败)
- **验证**: 本地 http.server + Chrome dump-dom → background-image: url(http://localhost:8899/static/logo.png) ✅; 部署后线上同样验证两处均为绝对 URL ✅
- ⚠️ **经验**: 静态资源绝对路径在 H5 必须运行时拼接 origin, 不能依赖 Vite 处理(publicPath=./ 会改相对); 排查图片用 Chrome --dump-dom 看 uni-image 内部 background-image 值
- 版本: 1.11.48 → 1.11.49
