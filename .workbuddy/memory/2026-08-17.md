# 2026-08-17 工作日志

## v1.11.150: 订单售后功能（商品/课程反馈 + 后台售后管理）

### 云函数 (dy-api/index.js)
- 新增 `aftersales` 集合支持，5 个接口：
  - `aftersale.submit`: 用户提交售后（校验订单归属+类型仅商品/课程，集合不存在时自动 createCollection 容错）
  - `aftersale.my`: 用户查自己的售后记录
  - `admin.aftersales.list`: 后台列表（可按状态筛选）
  - `admin.aftersales.reply`: 后台处理（回复+状态流转「处理中/已处理」+ 推送消息给用户）
  - `admin.aftersales.delete`: 删除记录
- MANAGER_ROLES 增加 3 个 admin.aftersales.* 路由（管理员可处理售后）

### 前端
- **共享组件** `src/components/aftersale-popup/aftersale-popup.vue`（easycom autoscan 自动注册 `<aftersale-popup>`）：
  - 历史售后记录展示（含 cloud:// 图片转签名 URL、商家回复回显）
  - 新增反馈表单（textarea 500字 + 图片上传最多3张，复用 feedback.vue 的 getStorage+resolveCloudUrl 模式）
- **订单列表 list.vue**: 商品/课程订单且非待付款 → 显示「售后」按钮（有处理中记录显示「售后中」高亮）；onShow 同步拉取售后记录
- **订单详情 detail.vue**: action-bar 放开已完成/已退款状态显示，商品/课程订单显示「售后反馈」按钮

### 后台 dashboard.vue

- 处理弹窗：显示订单详情+问题描述+图片，状态 pill 选择，回复 textarea，确认后推送消息
