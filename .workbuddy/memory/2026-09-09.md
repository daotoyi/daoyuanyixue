# 2026-09-09 工作日志

## v1.12.30 — 课程课时数与实际同步 (fix)
- **现象**: 书法精品课45讲, 课程页显示 42 课时, 实际 episodes 有 45 条.
- **根因**: `lessons_count` 是课程文档里一个**手工字段**, 从未与实际 `episodes` 数组同步, 会过期. 学员列表(course.vue:45)/详情页(detail.vue:71,72,157,181)/后台列表(dashboard.vue:486)/我的课程 都读它.
- **修法(读层统一重算, 永不过期)**:
  - `cloudfunctions/dy-api/index.js`:
    - `listCourses`: 返回前 `c.lessons_count = (c.episodes||[]).length`
    - `getCourse`: `course.lessons_count = course.episodes.length` (无 episodes 置 0)
    - `myCourses`: 内部角色分支 + 用户分支都重算 `lessons_count`
    - `adminCourseCreate`: `lessons_count: episodes.length` (不再采用手工输入)
    - `adminCourseUpdate`: 当 payload 带 `episodes` 时 `doc.lessons_count = data.episodes.length`
  - `src/pages-sub/admin/dashboard.vue`: 课程编辑表单「课时」输入框改为 `:value="courseForm.episodes.length"` 只读, 显示实际上传课时条数, 避免手工字段误导.
- **验证**: 线上 `courses.list` 书法精品课 `lessons_count=45` == `episodes.length=45` (前为 42). 对全部课程永久生效.
- **部署**: H5 重建重传 83/83 到 /h5/ (v1.12.30 c4ebd0f); 云函数 dy-api 重部署; 小程序 dist/build/mp-weixin 已构建(含 c4ebd0f), 待用户上传填 1.12.30. main + tag v1.12.30 已推 GitHub.
- **经验(铁律)**: 任何"手工维护的计数/统计字段 vs 实际数组"的不一致, 一律**在读接口重算** + **保存时同步落库**, 不要依赖手工字段; 前端展示直接读重算后的值即可.
