  - 修复: `src/pages.json` 把上述三页从 `subPackages[0].pages` 移到主包 `pages` 数组(路径仍写 `pages-sub/product/detail` 等, **路由完全不变, 所有现有跳转无需改**)。主包仅 216K, 移入后远低于 2MB 上限。编译产物 app.json 已确认三页进主包、子包不再含。→ 分享落地不再依赖子包下载, 根治 10003026。

  - SVG 原始 stroke=`#333`, 我改为主题色 `#55524c` 保持与收藏/界面一致; base64 存为 script 常量 `SHARE_SVG`, 模板 `:src` 绑定。
- **改动**: product/detail.vue 与 course/detail.vue 模板 `<view class="share-icon">` → `<image class="share-icon" :src="SHARE_SVG" mode="aspectFit">`; CSS `.share-icon` 改为 `width/height:16rpx`(PC 12px), 删除原纯 CSS 循环箭头绘制; `.heart` 24rpx→16rpx(含伪元素/PC 12px)。
- **版本流程**: bump→改代码+记忆→commit aba8d47→`git tag -f v2.0.10`→gen-version(aba8d47)→三端构建(均 DONE, H5 仍用 mv 旧 dist 绕过 safe-delete)→H5 部署(83/83 成功)→线上验证 detail.css 含 `.heart...width:.5rem`(16rpx)、product-detail chunk 含 SVG base64。
