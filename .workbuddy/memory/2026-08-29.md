## 微信支付"小程序违规"排查 (8-28 晚, 延续)
- 现象：requestPayment:fail 小程序违规，支付功能暂时无法使用；站内信无违规、虚拟支付已开通、支付权限 OK
- **根因确认：小程序未接入「订单信息录入」(订单管理)**——微信 2024-11 起强制交易类小程序接入，不接入禁用支付
- 解决：微信后台 → 支付与交易 → 订单管理 → 订单信息录入 → 填 `pages-sub/order/detail?order_no=${商品订单号}`（⚠️ 分包路径必须带 -sub，填 pages/order/detail 会报"无效的路径"）
- 发货信息：无需每单手动填——课程虚拟订单支付成功自动上报(logisticsType=3)；实体商品后台发货时填物流公司+运单号自动上报(logisticsType=1)；⚠️ 微信要求 48 小时发货时限
