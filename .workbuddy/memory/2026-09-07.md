# 2026-09-07 工作日志

## 订单详情页"取消订单"不生效 (v1.12.16)
- **现象**: 订单详情页(detail.vue)点"取消订单"没反应/不生效, 订单列表(list.vue, 即用户"我的-订单管理")点取消正常
- **根因(双重)**:
  1. 前端差异: list.vue doCancel 成功后 `await loadOrders()` 重拉列表(视觉生效); detail.vue doCancel 只改本地 `order.value.status`, **不重新拉取**, 一旦 order.value 是图片解析后的转换对象或取消失败, 界面不更新 → 表现为"不生效"
  2. 后端差异: dy-api `cancelOrder`(index.js ~2150) 对"待发货(已支付)"订单取消会调微信退款 API, **退款发起失败则 `return fail` 直接阻断**(订单状态不变) → 已支付订单取消不生效; 未支付(待付款)订单直接 update 不受影响
- **修复**:
  - 前端 `src/pages-sub/order/detail.vue` doCancel: 用 `order.value.order_no || orderNo.value` 兜底; 成功/失败都 `await load()` 重拉详情(对齐列表页); 退款失败提示"退款将在后台处理"(`res.refund_failed`)
  - 后端 `cloudfunctions/dy-api/index.js` cancelOrder: 退款分支(微信/余额/兜底)失败不再 `return fail` 阻断, 改 `refundFailed=true` 并 `status: refundFailed?'已取消':'已退款'` + 写 `refund_failed`/`refund_error`; 返回 `ok({updated:true, refunded:!refundFailed && status==='待发货', refund_failed:refundFailed})`。订单一定取消, 退款失败留后台处理
