## 10:50 首页推荐 PC/移动端独立显示彻底修复 v1.11.210 (fix)

  1. rec- base 块(含 .pandao-cover/.rec-pd-img/.rec-moment-*)整体移到 @media 1025px **之前** → media 规则真正生效
  2. media 内 rec- 规则从 570px/660px 固定值改为 **v1.11.208 base 的 rpx 值**(卡片330rpx/图195rpx/标题26rpx/moment 420rpx/225rpx 等, 逐项取自 git show v1.11.208) → PC 显示与 208 线上逐像素一致
