## H5 手机端微信支付兜底（v2.0.22, commit 15b65ca）

**现象**：课程/商品在手机 H5 支付失败，提示「商户号该产品权限预开通中，请等待产品开通后重试」。

**定位过程（关键结论，别只凭提示瞎猜）**：写了临时脚本直连 `wxpay-v3` 实测三条通道（下单后立即关单，不是真实支付）：
| 通道 | appid | 实测 |
|---|---|---|
| H5 支付 | GZH_APPID `wx856077bf8275d276` | ❌「商户号该产品权限预开通中」 |
| Native 扫码 | WXPAY_APPID `wx3ec1337aae9ace3c` | ✅ 正常返回 code_url |
| JSAPI | WXPAY_APPID | ✅ 权限通（返回「无效的openid」= 我校验用的假 openid，非权限问题） |

→ 根因在**微信商户平台**：商户号 `1116271440` 的「H5 支付」产品仍处预开通状态。与买商品/课程无关，只取决于在哪个端付款。小程序内支付、PC 扫码均正常。

**兜底实现**（本次代码）：
- 新增 `src/utils/h5pay.js`：`isH5PayUnavailable(msg)` 正则命中 `预开通|未开通|产品权限|H5\s*支付|NO_AUTH|PRODUCT`；`payByWxmpScheme(wxmpSchemeFn, orderNo)` 调后端已有 `pay.wxmpScheme` 拿 URL Scheme 跳小程序；`isInWeChatBrowser()` 用 `MicroMessenger` UA 判断——**微信内置浏览器不允许自己唤起自己，scheme 必被拦截**，此情形返回 `inWechat:true` 让调用方给文字指引；`wxmpFallbackTip()` 统一两套提示文案。
- 接入两处支付入口：`src/pages-sub/checkout/checkout.vue`（下单页）、`src/pages-sub/order/detail.vue`（订单详情重新支付），均在 H5 手机分支 `wxpayH5` 抛错且命中上述正则时自动降级；失败走 `showModal` 给指引而非一闪而过的 toast。
- 精准降级原则：**只在「权限类」错误时换通道**，金额/参数/风控错误仍原样提示，避免掩盖真实问题。
- 三端校验：H5 产物独立出 `assets/h5pay.*.js`（含「预开通」「在浏览器打开」文案）；小程序两端 `checkout.js` 内 `navigator.userAgent` 计数 0 → 条件编译未泄漏 H5 代码。

**线上实测**：`https://club.zhenhesheng.cn/h5/assets/h5pay.*.js` HTTP 200；版本 `v2.0.22 (15b65ca)`；H5 首页 200；main `83dbcb5..f05cb84` + tag v2.0.22 已推。

**待用户侧动作（根本解决）**：微信支付商户平台 → 产品中心 → H5 支付，完成开通申请 + 「开发配置 → H5 支付域名」加 `club.zhenhesheng.cn`，审核通过后即可去掉兜底依赖。

## 后台顶部导航栏 棕色 → 渐变中国红（v2.0.21, commit 68f91f4）
- 定位：用户说的「最顶部『道元易学 · 管理后台』背景框」= `pages.json` 里 dashboard 页的 `navigationBarBackgroundColor: #451A03`（深棕），不是侧边栏（侧边栏本来就是 #9c1630 红）。
- 改法（两段式，因原生导航栏不支持渐变）：
  1. `pages.json` dashboard → `#C41E3A`（中国红纯色），微信/抖音产物 `navigationBarBackgroundColor` 均已确认为 `#C41E3A`；
  2. H5 端叠加真渐变 `linear-gradient(90deg, #e8112d, #c41e3a 52%, #8c0f1f)`。
- **关键坑：写在页面 `<style>` 里的 `uni-page-head` 选择器会被编译加 `[data-v-xxx]`，而 uni-page-head 是页面根节点之外的复用节点，永远匹配不到 → 渐变静默失效**。
  正确做法：样式放 `App.vue` 全局 `<style>`（非 scoped，用 `/* #ifdef H5 */` 包），并在 dashboard `onMounted` 用 `document.querySelector('uni-page-head')?.classList.add('dy-nav-red')` 挂类、`onUnmounted` 移除 —— uni H5 全站复用同一个 uni-page-head，加类标记才能做到「只后台生效，不污染商城等页面」。
- 校验：线上 `static/index.css` 含无 scope 的 `.dy-nav-red` 渐变规则；`version.*.js` = `v2.0.21 (68f91f4)`；H5 200。
