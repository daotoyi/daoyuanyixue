## 22:38 真正根因: 微信v3查单签名bug (fix, 最关键)

- **用户反馈**: 再次支付提示已支付, 但订单状态不更新也不跳转
- **真正根因**: `wxpay-v3.js` 的 request() 签名时用 `path.split('?')[0]` 把 query string 剥掉了! 微信 v3 签名规范要求**签名串 URL 必须含 query**(如 `/v3/pay/transactions/out-trade-no/xxx?mchid=1116271440`)
  - POST 下单无 query → 签名正确 → 下单成功
  - GET 查单带 `?mchid=` → 签名错误(SIGN_ERROR) → **pay.querySync 兜底从未成功** → 订单永远不同步、不跳转
- **修复**: request() 增加 `signPath = query ? path + '?' + new URLSearchParams(query).toString() : path`, 签名与请求 URL 完全一致
- **验证**: 本地+线上查单返回 trade_state=NOTPAY(真实状态, 不再是 SIGN_ERROR)
- **部署**: dy-api 已更新; git e69ecf5 已push
- **铁律**: 微信支付 API v3 签名, GET 带 query 必须把 query 拼进签名串! (POST 不带 query 的天然正确, 容易被忽略)
