## 环境故障恢复 (2026-10-14 实测, 已记入 MEMORY.md 铁律)
- **症状**: `mcporter call cloudbase.*` 任何 action 都报 `ECONNREFUSED 127.0.0.1:60204` —— 非认证过期, 是 cloudbase-mcp 本地代理进程挂了。
- **根因**: cloudbase-mcp 配置写死 node 路径 `.../node/versions/22.22.2/bin/node`, 但托管目录已重命名为 `22.22.2-6`; 旧 daemon 进程占着已删二进制故此前可用, 一旦 `mcporter daemon restart` 新进程即 ENOENT。
- **恢复三步**:
  1. `cd ~/.workbuddy/binaries/node/versions && ln -sfn 22.22.2-6 22.22.2`(让旧路径复活, 不删任何东西)
  2. `npx -y mcporter daemon restart`(清 cloudbase offline 缓存)
  3. 认证多半已 REQUIRED → 设备码重授权 `npx -y mcporter call cloudbase.auth action=start_auth authMode=device` 拿 user_code+verification_uri, 浏览器授权后 `auth action=status` 确认 READY 再部署
- 注: 托管 node 真实目录是 `22.22.2-6`(非 `22.22.2`), 部署/构建用 `22.12.0` 或 `22.22.2-6` 均可; 该符号链接仅供 cloudbase-mcp 旧配置兜底。

- **后台系统可完全共用, 零改后端**: dy-api 是纯 HTTP 云函数按 action 分发, 平台无关; 所有业务数据(盘道/商品/课程/会员/订单/固定成员)存 CloudBase 数据库, 后台设置天然同步到各端。这是用户最关心的"各平台效果同步"——天生满足。

### 抖音「小程序通用上传分支」剥离设计文档 (2026-10-14 追加)
- 用户要求把上传分支剥离方案细化成设计文档 → 已写入 `docs/douyin-upload-design.md` (未改代码, 纯设计)。
- 核心诊断: 抖音端(MP-TOUTIAO)会命中 `cloudbase.js` 的 `#ifndef MP-WEIXIN` 分支, 该分支强依赖浏览器 API(fetch/document/canvas/Blob/FormData) → 抖音非浏览器环境全缺失 → 上传必崩(`fetch is not defined`)。
- 方案要点:
  1. 抽平台无关工具: `compressImageMini`(uni.compressImage, 替代 canvas) + `readFileBase64`(uni.getFileSystemManager readFile base64, 替代 fetch) + `uploadImageBase64Mini`(uni.request POST 网关 `storage.uploadBase64`, 与 H5 同款零后端改)。
  2. `getStorage()` 新增 `#ifdef MP-TOUTIAO` 分支: 图片走上面三件套; 视频首版降级抛 `DY_NOT_SUPPORTED`。微信分支(wx.cloud.uploadFile)与 H5/App 浏览器分支保持不变。
  3. `initCloudBase()` 抖音分支直接 `return null`(业务请求走 uni.request 不依赖 SDK); `getAuth()` 抖音分支返回 `{getLoginState: async()=>null}`(首版登录走 phoneLogin, 不依赖微信 openid)。
  4. 利好确认: `api.js` 的 `_callFunction` 非微信分支直接用 `uni.request(API_BASE)` 打 TCB 网关、不依赖 SDK → 抖音命中零改动; 文件 URL 走 `app.fileUrl` 网关(零后端改)。
  5. 合法域名坑: `api.js` 实际请求 `…ap-shanghai.app.tcloudbase.com`, 而 `_tcb_domains` 列的是 `…tcloudbaseapp.com`(不同子域); 抖音端需在**抖音开放平台后台**手动配 request 合法域名(manifest 的 `_tcb_domains` 仅注入微信端)。
  6. 视频分片 `uploadMultipartToCos` 小程序化列为选做(替换 fetch→uni.request PUT、new Blob→ArrayBuffer), 首版不建议做。
- 工作量(首版含图片上传): 约 2 天; 视频分片选做 +1.5 天。
