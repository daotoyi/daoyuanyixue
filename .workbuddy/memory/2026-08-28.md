## 视频上传 failed to fetch 最终解决 (v1.11.217 后续)
- **根因确认**：COS bucket CORS 白名单不含 club.zhenhesheng.cn → 浏览器向 COS 发 POST 被跨域拦截
- **修复**：用 COS 官方 SDK (cos-nodejs-sdk-v5) + CloudBase 临时密钥 (`auth get_temp_credentials`) 查询/修改 bucket `636c-cloud1-d8gs2k9m311f7272f-1464523137` 的 CORS，加入 `https://club.zhenhesheng.cn` / `http://club.zhenhesheng.cn` / www 变体
- **临时密钥方法**：`npx -y mcporter call cloudbase.auth action=get_temp_credentials envId=... confirm=yes reveal=true` → secretId/secretKey/token
- **工具脚本**（可复用）：`/tmp/cos-cors.js`（手写签名 get/put）与 `/tmp/cos-sdk.js`（官方 SDK get），`/tmp/cos-add-cors.js`（自动追加域名）；本地 npm 装 cos-nodejs-sdk-v5
- 验证：`cos.getBucketCors` 确认白名单已含 club.zhenhesheng.cn ✅
